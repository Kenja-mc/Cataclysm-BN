# 制限付きゾンビ復活 (Limited Zombie Revival)

`No_Reviving`（復活を完全に禁止するMOD）を参考に作った、**禁止ではなく制限する**MODです。
ゾンビは今まで通り起き上がりますが、死体の壊れ具合に応じて弱く・遅くなり、そして何度も起き上がることはできません。
対象は **species が ZOMBIE のもの** だけです。ロボットの自己修復など、他の「復活する存在」には手を触れません。

このMOD（ドキュメントを含む）は、大部分をClaude Opusくんの力を借りて作ったMODです。
安定版v0.12、開発版v260922で動作を確認しております。

---

## 1. 前提：BN本体が元々やっていること

このMODを理解するうえで重要なので、先に本体の仕様を整理します。
「損壊した死体ほど復活が遅く、弱くなる」処理は**既に本体にあります**。
ただし `REVIVES_HEALTHY` がそれを台無しにしており、また一度弱った個体を倒しても
その死体はまた最初から起き上がれてしまいます。

## 2. このMODが足すもの

1. **`REVIVES_HEALTHY` の無効化**（JSON側、`monster_adjustment`）
   → 万全の状態で起き上がるゾンビがいなくなり、本体の減衰が常に効くようになります。
2. **復活時HPの上限**を損壊度ごとに設定（無傷 65% → ボロボロ 25%）。
   本体の計算結果の方が低いときはそちらが優先されるので、**弱くする方向にしか働きません**。
3. **起き上がり直後の無力時間**。損壊度に応じて5〜30秒、転倒＋朦朧状態になります。
   「もぞもぞと起き上がろうとしている間に頭を潰せる」ための猶予です。
4. **死後硬直**（このMOD独自の効果 `lrz_rigor`）。2〜12分間、移動速度が -10〜-40 されます。
5. **復活回数の上限**（初期値1回）。蘇った個体を倒すと、その死体は `PULPED` 扱いになり
   二度と起き上がりません。見えていれば「〜は壊れすぎていて、もう起き上がれない。」と表示されます。

### 損壊度別の数値（初期設定）

| 死体の損壊度 | 復活時HP上限 | 無力時間 | 死後硬直 | 速度低下 |
|---|---|---|---|---|
| 0（無傷） | 最大の65% | 5秒 | 2分 | -10 |
| 1 | 50% | 12秒 | 5分 | -20 |
| 2 | 35% | 20秒 | 8分 | -30 |
| 3（ボロボロ） | 25% | 30秒 | 12分 | -40 |

本体の復活待ち時間（約6〜24時間）はそのままなので、
「損壊が酷いほど復活が遅い」という部分は本体の仕組みをそのまま活かしています。

## 3. 設定の変え方

`main.lua` の冒頭にある `mod.cfg` を書き換えるだけです。

```lua
mod.cfg = {
  max_revivals = 1,   -- 同じ死体が起き上がれる回数（0にすると復活禁止MODと同じ挙動）
  hp_ratio  = { [0] = 0.65, [1] = 0.50, [2] = 0.35, [3] = 0.25 },
  rise_secs = { [0] = 5,    [1] = 12,   [2] = 20,   [3] = 30 },
  rigor_mins= { [0] = 2,    [1] = 5,    [2] = 8,    [3] = 12 },
  announce  = true,   -- 死体が完全に沈黙したときのメッセージ
  debug     = false,  -- 詳細をデバッグログに出す
}
```

`main.lua` はホットリロード対応です。ゲーム中にファイルを書き換えて
デバッグメニューの **Reload Lua Code** を実行すれば即座に反映されます。
速度低下の幅だけは `effects.json` 側（`speed_mod`）なので、こちらはワールド再読み込みが必要です。

## 4. 導入方法と注意点

- フォルダごと `data/mods/` または ユーザーディレクトリの `mods/` に置いてください。
- **Lua対応ビルドが必要です**（`lua_api_version: 2`）。公式のWindows配布版は対応しています。
  Lua非対応のビルドで有効にすると、MOD読み込み時にエラーになります。
- `No_Reviving`（復活禁止MOD）とは**併用しないでください**。あちらが `REVIVES` を消すので、このMODの出番が無くなります。
- 既存のワールドに後から追加できます。ただし、既にマップ上にある死体には「何度目の復活か」の記録が無いので、追加後の1回目は普通に起き上がります。
- ゾンビ奴隷（zlave）として自分で蘇らせた個体は対象外です。
