# Common CDDA / BN complaints (research summary)

An AI research pass, done with limited access: Reddit, Steam reviews and the Discourse forum blocked
direct fetches, so the evidence is search snippets plus GitHub issue metadata. Frequency ratings are
judgement, not counts.

| #  | Complaint                                        | Frequency         | Fork status                                                                                                    |
| -- | ------------------------------------------------ | ----------------- | -------------------------------------------------------------------------------------------------------------- |
| 1  | Steep learning curve, weak onboarding            | very common       | welcome card, key hints; no guided first day yet                                                               |
| 2  | Documentation hard to find or outdated           | common            | open                                                                                                           |
| 3  | Keybindings overwhelming and non-standard        | very common       | WASD, hint strip, classic toggle; discoverability of the long tail open                                        |
| 4  | Poor mouse support in the terminal               | common            | click-to-travel, right-click examine; Sword of the Stars style tile selection (hover, click, right-click menu) |
| 5  | Hard to read at a glance                         | common            | themes; glyph density open                                                                                     |
| 6  | Nested containers and pockets                    | very common (DDA) | BN mostly avoids pockets                                                                                       |
| 7  | Item bloat                                       | common            | about 480 items folded into variants                                                                           |
| 8  | Loot zones tedious and undiscoverable            | occasional–common | quick stack and sort pile                                                                                      |
| 9  | Crafting and construction UI                     | common            | 12-tile reach; craftable-now default and construction search open                                              |
| 10 | Early-game death spirals                         | very common       | open                                                                                                           |
| 11 | Realism bookkeeping (pain, stamina, encumbrance) | common            | BN already lighter                                                                                             |
| 12 | Developer removals ("realism" changes)           | common in DDA     | the fork adds toggles, never removes                                                                           |
| 13 | Performance and load times                       | occasional        | migration finalization fixed                                                                                   |
| 14 | No coherent end game                             | occasional        | open                                                                                                           |
| 15 | NPC and faction camp friction                    | occasional        | open                                                                                                           |

Things players love and would hate to lose:

- deep simulation and emergent stories;
- moddability and JSON compatibility, which is why every fold ships migrations;
- open-ended playstyles, vehicles and base building;
- the classic keybindings, kept as a toggle;
- small options and toggles;
- BN's lighter micromanagement.
