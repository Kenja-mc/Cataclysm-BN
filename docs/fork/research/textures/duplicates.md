# Duplicate and blank sprite report for the bundled tilesets

Generated by `/tmp/texture-sweep/dupes.py` (data: `dupe_groups.csv`, `cross_tileset.csv`, `blank_or_solid.csv`, `totals.csv`).

Method: every sheet named by a `tiles-new` entry in each `gfx/<tileset>/tile_config.json` and in every `data/json/external_tileset/*.json` is decoded to 8-bit RGBA. Each sprite cell is hashed (md5 of its exact pixels) and a second hash is taken of the non-transparent bounding box, which catches the same art at a different offset. Sprite indices are counted per JSON file, resetting for each file and accumulating across its `tiles-new` sheets, as in `cata_tiles::tileset_loader::load_internal`.

An id defined more than once in the same file keeps its last definition, matching `tileset::create_tile_type`, which overwrites. Sheets whose name starts with `fallback`, `filler`, `temporary`, `unknown` or `incomplete` are treated as placeholder art: their groups are counted in section 4 but excluded from section 1, because every id there is expected to look the same.

Only foreground sprites make two ids indistinguishable, so section 1 uses `fg` references only; a shared `bg` ground texture is intended layering. Section 2 counts both `fg` and `bg`, because a sprite can be foreground in one tileset and background in another.

### Visual check

`dupes-top.png` crops the cited ids of the ten highest-ranked groups (three ids each, native pixels scaled 4x with nearest neighbour, tile id under each cell). I viewed it: within every group the cells are the same drawing, pixel for pixel. Nothing in the silhouette, palette or outline separates the ids, so on the map they are indistinguishable; only the item or monster name in the UI tells them apart. The three consequences that matter most are the dog group (the mutant dog is drawn exactly like domestic breeds), the hallucination pair (the hostile and the harmless version are the same sprite) and the liquid groups (water, ethanol and methanol share one bottle in RetroDays+; bleach and sulphuric acid share one blob in MSX++).

## Notes and limits

- Hashes compare exact pixels, including alpha; two sprites that differ by one alpha level are not reported as duplicates, so the counts are lower bounds.
- Cross-tileset matches only exist when the two sheets use the same sprite size, because a cell of a different size cannot contain the same pixels.
- Sprite sheets referenced by `data/mods/*/mod_tileset.json` are out of scope here; only `gfx/` tilesets and `data/json/external_tileset/` are covered.

Total per-tileset duplicate groups: 7017; distinct content findings: 2947. Groups on placeholder sheets: 424. Sprite-cell groups whose members differ only in transparent padding (same art shifted or padded inside the cell): 963.
