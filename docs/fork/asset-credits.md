# Bundled game assets: credits and licenses

Inventory of this checkout and its locally installed asset packs. This is a source-backed
credits index, not a legal clearance certificate. Asset groups are listed with their original
credit files; those files retain the detailed per-sprite, per-sound and per-track credits.

## Scope and license evidence

- **Project default**: [CC BY-SA 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/),
  as stated in [LICENSE.txt](../../LICENSE.txt). A default is not proof that every imported asset
  has a verified provenance chain. Explicit asset notices take precedence.
- **Versioned assets**: tilesets, fonts, Basic/Overhaul sound effects, core content and in-tree mods.
- **Optional local download**: Otopack BN Mk 2 is present under `data/sound/`, but is downloaded
  separately by [the installer](../../bin/install-cataclysm-bn.sh). It is not covered by the
  Overhaul pack's CC0 declaration.
- **Packaging caveat**: [data/CMakeLists.txt](../../data/CMakeLists.txt) copies the data directory
  during release installation. An optional downloaded pack present in that directory can enter
  a package; “downloaded separately” is not a redistribution permission.
- Code libraries, system dependencies and build-tool dependencies are outside this **game-asset**
  inventory. Existing code notices remain in [LICENSE.txt](../../LICENSE.txt) and vendored sources.

New installations use bundled **JetBrains Mono NL Regular** for UI, map text and overmap
text, with **Unifont** as the final fallback. No system font installation is required.
The no-ligature face keeps character-cell symbols separate. **Font blending** enables
anti-aliased text. The default size is 18, with 11 × 24 pixel UI cells and square 24 × 24
map/overmap cells; these accommodate the face's 600-unit advance and 1320-unit line height
per 1000 units/em.

Existing user `fonts.json` files are retained, including custom typefaces. To opt in,
edit the `fonts.json` in the game's config directory: put `JetBrainsMonoNL-Regular.ttf`
first and `unifont.ttf` last in each of `typeface`, `map_typeface` and `overmap_typeface`.
Keep any additional desired fallbacks between them. Restart after changing fonts or
font dimensions; font width, height, size and blending are separate graphics options.

The bundled pair covers the HUD's Unicode weather, combat, stance and need symbols
(`☼ ☾ ☁ ☂ ↯ ❄ ◎ ▼ ✶ ⚔ ⌖ ➶ ☯ • ▶ ━ ✦ ⊕ ▤ ☹ ☕ ♨ ° ◷ ⊙`) and box drawing. Several symbols come
from Unifont rather than JetBrains Mono. Neither face supplies the HUD's **Nerd Font**
private-use icons, including U+F255 and the U+F0000–U+FFFFD range; that optional style
still requires a user-provided compatible Nerd Font in the fallback list. The bundled
Unifont primarily covers the Basic Multilingual Plane, not general emoji or supplementary
plane pictograms; do not assume a newly chosen icon is available.

## Attribution and redistribution gaps

1. **Otopack is not blanket-cleared for redistribution.** Keep the registry label and per-file
   notices; resolve missing rights before bundling it into a redistributable release. A source URL,
   an uploader's “not copyrighted” claim, fanmade status or possession of a file is not a license.
2. **Sokoban / Thinking Rabbit**: imported puzzle layouts have a copyright credit but no explicit
   permission in their header.
3. **LARWICK bitmap font**: creator and file-specific license are not established by local notices.
